Plant Disease Detection and Treatment Tracking Using AI and Fuzzy Logic

A graduation project in Artificial Intelligence developed by Ehmed Silêman.

Project Overview

The project presents an intelligent system for detecting plant diseases by analyzing images of plant leaves.

A user captures or uploads an image of a plant leaf. An Artificial Intelligence model analyzes the image and identifies the possible disease based on visual symptoms.

The system also uses Fuzzy Logic as part of the treatment tracking and decision-support process.

Artificial Intelligence

The Artificial Intelligence component analyzes plant leaf images and performs disease detection using image-based machine learning and computer vision techniques.

Fuzzy Logic

Fuzzy Logic is used in the treatment follow-up process to evaluate multiple conditions and support treatment-related decisions using fuzzy rules.

Main Features

  • Plant leaf image analysis
  • AI-based plant disease detection
  • Image classification
  • Computer Vision
  • Treatment tracking
  • Fuzzy Logic decision support
  • Disease and treatment information
