Plant Disease Detection and Treatment Tracking Using AI and Fuzzy Logic

Artificial Intelligence Graduation Project

This project presents an intelligent system for diagnosing plant diseases by analyzing images of plant leaves.

The project was developed as part of a graduation project team at the Faculty of Informatics Engineering, Damascus University.

Project Contributor: Ehmed Silêman
Specialization: Artificial Intelligence

Project Overview

The system is designed to assist users in identifying plant diseases through leaf-image analysis and to provide treatment recommendations, preventive guidance, and treatment follow-up.

The project combines Artificial Intelligence, Computer Vision, plant-specific disease classification, geographic information, and Fuzzy Logic.

System Architecture

Leaf Image + Plant Name + Geographic Location The user captures or uploads a plant leaf image and provides plant information and location.

Dual-Stage Classification

One of the main technical concepts of the project is its two-stage classification approach.

Stage 1 — Plant Type Verification

The first classifier analyzes the uploaded leaf image and verifies whether it belongs to the plant selected by the user.

If the plant type does not match, the system can alert the user about a possible input or recognition error.

Stage 2 — Disease Classification

After confirming the plant type, a second classifier analyzes the image using only disease classes associated with that specific plant.

This plant-specific classification approach is designed to reduce ambiguity between unrelated diseases and improve diagnostic precision.

Artificial Intelligence & Computer Vision

The project investigates image-based Artificial Intelligence techniques for detecting visual symptoms of plant diseases.

The technical design considers Computer Vision and Deep Learning concepts such as:

  • Convolutional Neural Networks (CNN)
  • Transfer Learning
  • Image Classification
  • Feature Extraction
  • Object Detection
  • Semantic Segmentation
  • Softmax Classification

The project design also examined lightweight neural-network architectures suitable for mobile-oriented applications.

Fuzzy Logic

Fuzzy Logic is integrated into the treatment follow-up process.

Rather than relying only on strict binary rules, the fuzzy system evaluates treatment-related conditions using fuzzy rules and supports treatment follow-up and decision-making.

Treatment & Prevention

Following disease diagnosis, the system can provide:

  • The probable disease name
  • Suggested treatment
  • Recommended active substances
  • Preventive recommendations

Geographic Disease Analysis

The system can use geographic location information to identify plant diseases reported or commonly found in the user's surrounding region.

This information can support preventive action and improve awareness of disease patterns in different geographic areas.
